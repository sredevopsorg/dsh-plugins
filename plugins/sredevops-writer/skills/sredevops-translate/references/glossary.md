# English → Spanish glossary

Use this map consistently within an article. When two options are listed, the first is preferred; the second is acceptable when the English form is what practitioners actually use.

Standing corrections in `../../../references/editorial-memory.md` override this table where they conflict. If a rule changes a term here, update this row too, but treat the memory as the authority.
